# 读心术 · Mindscape

> 原「角色人物多维分析系统」。这一版重写了分析内核、界面与 AI 接入方式。

读懂一个人：基于证据的人格研判、意图解读与对话模拟。

理解一个人，从承认自己看不透开始。

---

## 这一版改了什么

### 1. 分析内核：从「打九个分」到「可证伪的研判」

旧版的做法是让模型给九个维度各打一个分，再配一批「温暖、善解人意」式的标签。问题在于：
这种输出**放在任何人身上都成立**，无法被现实推翻，因此既不像心理学，也没有实际用处。

新版要求模型按证据链输出：

| 旧版 | 新版 |
|---|---|
| 九个分数，全部必填 | 证据不足的维度**留空**，显示「证据不足」而不是 0 分 |
| 一句话性格总结 | 核心结论 + 内在冲突 + 维持循环 + 发展性推测 |
| 性格标签 | 特质分五层：主结论 → 子面 → 支持证据 → 反证 → 边界条件 |
| 「真实意图推测」 | 2–4 个**竞争假设**，各自带概率、支持/反对证据、**证伪条件** |
| 泛泛的建议 | 可验证预测（附「如果错了说明什么」）+ 机制化的相处建议 |
| 未配置 AI 时编造分数 | 未配置时**如实说「无法分析」**，绝不伪造 |

新增五个分析层：**动机结构**（需要/恐惧配对、价值排序、回避目标）、**防御与调节**（防御机制成熟度、归因风格、压力应对）、**关系模式**（依恋双维度、人际环位置、不安全时的策略）、**自我叙事**（核心信念、身份冲突、盲区）、**形成性解释**（核心冲突、触发点、恶性循环）。

### 2. 「读心」需求的正确定义

你想知道对方真实意图——这件事没法靠「AI 猜」解决。系统改为：给出**情境线索 → 多种可能解释 → 各自的证伪条件 → 你还需要观察什么**。
真正能确认的，永远是后续观察，而不是某一次推断。

### 3. 界面：移动端优先

- **底部标签栏**常驻四个主入口，桌面端换成左侧边栏，任何尺寸下都不需要翻找
- **人物详情**用横向分段导航（研判 / 读意图 / 对话 / 记录），一屏即达
- 所有点击目标 ≥ 44px，输入框 16px 字号（避免 iOS 聚焦缩放），适配安全区
- 暗色纸墨质感 + 中文衬线标题，替换掉原先的浅色卡片堆叠

> 顺带修了一个移动端硬伤：旧版把 API 地址写死为 `http://localhost:3000`，
> 手机通过局域网访问时所有请求都会失败。现在默认走相对路径。

## 核心功能

**人物库** — 首页即档案库。最近研判的大卡片直接显示核心结论与人格轮廓条。

**研判入口** — 公众人物：输入姓名。身边的人：结构化访谈，引导你描述**可观察的行为**而非印象（「TA 很冷漠」无法分析，「我说话时 TA 一直看手机」可以）。

**人物详情** — 四个板块：
- 研判：完整分析档案
- 读意图：针对具体情境的竞争解释
- 对话：以对方思维方式回应，每条可展开「为什么这么说」
- 记录：追加新观察，用全部材料重新研判（而非在旧结论上加固）

**反事实推演** — 对比两种做法分别触发对方什么机制。

**自我认知** — 日记式记录。每次提交用全部材料重新分析，不做加权平均（那会把早期偏差永久固化）。第一人称材料特别标注自我服务偏差，并把**盲区**作为独立板块。

**情景短片** — 按研判结果生成一段视频，用于回看互动方式。

## 领域框架：不同的人用不同的尺子

同一个人格九维套在诗人、将领、企业家身上，雷达图长得都差不多——那是模板填空，不是分析。

现在按人物领域自动切换维度集合（共 10 套）：

| 域 | 适用 | 维度举例 |
|---|---|---|
| 人格结构 | 身边的人 / 自己 | 大五 + 决断、风险、共情、领导（**唯一有实证基础的域**） |
| 文学气质 | 诗人、作家 | 意象敏感、语言自觉、隐喻思维、现实疏离 |
| 军事才能 | 将领、开国君主 | 战略视野、临机决断、军心凝聚、政治嗅觉 |
| 商业能力 | 企业家、投资人 | 机会识别、资源整合、组织建设、长期主义 |
| 科研特质 | 科学家、工程师 | 抽象能力、怀疑精神、跨域联想、失败耐受 |
| 艺术特质 | 画家、导演、音乐家 | 感知敏锐、形式实验、受众直觉 |
| 政治手腕 | 政治家、改革者 | 权力敏感、联盟构建、妥协艺术 |
| 思想特质 | 哲学家、宗教人物 | 体系建构、悖论耐受、独立判断 |
| 竞技特质 | 运动员、棋手 | 身体控制、临场专注、压力表现 |
| 能力评估 | 动漫 / 游戏 / 虚构角色 | 战斗力、能力上限、战术智力、成长潜力、弱点暴露 |

模型先判断该用哪个域，再只按该域的维度评分。界面会标明这次用的是什么框架，
并明确区分「实证量表」（仅人格域）与「分析框架」（其余域是观察工具，不是心理测量）。

### 虚构角色

第三种研判模式。不套人格量表，只看能力：战斗力、上限、战术、成长、防御、速度、精神力、弱点。
依据是原作设定与战绩，不是现实史料。

## 安装到手机（PWA）

已支持「添加到主屏幕」，装好后全屏打开、有独立图标，用起来接近原生 App。

- **Android / Chrome**：访问后会弹出「添加到主屏幕」提示，或从浏览器菜单选择安装
- **iOS / Safari**：点底部分享按钮 → 「添加到主屏幕」

技术实现：
- `public/manifest.webmanifest` — 应用名、图标、主题色、快捷入口（新建研判 / 对话）
- `public/sw.js` — Service Worker 缓存策略
- `src/components/pwa/PWARegister.tsx` — 注册与安装提示

**缓存策略是刻意保守的**：
- 静态资源（JS/CSS/图标）cache-first，文件名带 hash 可放心长期缓存
- 页面导航 network-first，离线时回退缓存
- **所有 `/api` 请求一律不缓存**——研判、对话依赖实时数据，缓存会造成"看到的是旧结果"

> 注意：PWA 仍需联网，因为分析、AI 调用、数据库都在服务端。
> 若日后要做真正的 APK/IPA，需先解决数据库并发（SQLite → PostgreSQL）
> 与文件存储（本地磁盘 → 对象存储）。

## 主题：明暗双色

顶部右上角有常驻的主题按钮，桌面端在侧边栏底部。「我的 → 账号」里可以三档设置：

- **自动**：跟随系统的深色/浅色偏好
- **浅色**：暖白纸底，白天强光下不刺眼
- **深色**：深空底 + 青紫霓虹

选择存在 localStorage，切换不刷新页面、不闪白。首屏由内联脚本在绘制前定好主题。
所有颜色走 CSS 变量（`--bg-base` / `--fg-*` / `--accent`），组件里不写死色值。

## AI 引擎：用户自带密钥

分析质量取决于模型。系统允许每个用户选择自己的服务商并填入密钥：

- 内置 DeepSeek / OpenAI / Moonshot / 智谱 / 通义千问，以及自定义 OpenAI 兼容端点
- 保存前会**真实调用一次**做连通性测试，避免"存上了却用不了"
- 密钥只存服务端，接口只回传后四位掩码，永不下发到浏览器
- 未填自己的 key 时回落到服务端环境变量；两者都没有则明确提示"未配置"

入口在「我的 → AI 引擎」。默认面板只需要填密钥和对话模型；
**高级设置**（可折叠）里可分别配置**图像模型、视频模型及各自的接口地址**——
因为大多数供应商的对话、图像、视频是三套不同的模型，甚至不同端点。

| 用途 | 典型模型 | 是否可单独配 |
|---|---|---|
| 分析 / 对话 | `agnes-2.5-flash`、`deepseek-chat` | 默认面板 |
| 生成画像 | `agnes-image-2.1-flash`、`dall-e-3` | 高级设置 |
| 生成视频 | `agnes-video-v2.0` | 高级设置 |

留空的媒体模型会回落到服务商默认值，所以只配对话模型也能正常做文本分析。

## 本地启动

```bash
npm install
cp .env.example .env     # 填写 AI_API_KEY
npx prisma db push       # 建表；新增了 analysisProfile 字段，需要执行
npm run dev
```

手机调试：`npm run dev -- -H 0.0.0.0`，然后用 `http://<你的局域网IP>:3000` 访问。

### 环境变量

| 变量 | 必填 | 说明 |
|---|---|---|
| `DATABASE_URL` | ✅ | 默认 `file:./dev.db` |
| `JWT_SECRET` | ✅ | 生产环境用 `openssl rand -hex 32` |
| `AI_API_KEY` | | 服务端兜底模型。用户可在「我的 → AI 引擎」填自己的 key，此时无需配置 |
| `AI_API_URL` | | 默认指向 Agnes 兼容端点 |
| `AI_MODEL` | | 默认 `agnes-2.0-flash` |
| `AI_IMAGE_MODEL` | | 画像生成模型 |
| `NEXT_PUBLIC_BASE_URL` | | 留空即可（相对路径）。仅在前后端分离时设置 |

## 已知边界

- 分析质量高度依赖模型能力与材料充分度。材料稀薄时系统会显示「证据不足」，这是**预期行为**，不是故障。
- 单一视角的观察必然带偏差。系统会在 sources 里标明这一点。
- 历史人物的分析受史料与时代背景限制，模型若信息不足会把充分度打低。
- 本产品不是心理诊断工具，给出的都是概率性推断，**不能替代专业心理评估**。
- 「读心」在技术上不可能。系统能做的是：给出多种解释、标明各自证据与证伪条件，
  并告诉你还需要观察什么。把推断当作事实使用，会伤害真实的关系。

## 声明

分析结果是基于有限材料的概率性推断，不是对任何人的定论。真实的人会随情境与时间改变，
任何结论都应当被新的观察推翻或修正。
